# SecureWatch AI Brand Assets

Bu dizin SecureWatch AI projesinin onaylanmış Concept 1 logo ve marka varlıklarını içerir.

## Dosya Tanımları

- `securewatch-ai-logo-dark.png`: README ve koyu marka sunumu için ana tam logo. Koyu (Deep Navy) arka plan kullanır.
- `securewatch-ai-logo-light.png`: Açık zeminli (örneğin beyaz/açık gri alanlar) tam logodur.
- `securewatch-ai-mark-dark.png`: Koyu header, sidebar veya mobil alanlar için yalnız beyaz-cyan "S-Kalkan" işaretini içeren şeffaf zeminli logodur.
- `securewatch-ai-mark-light.png`: Açık alanlar için lacivert-cyan "S-Kalkan" işaretini içeren şeffaf zeminli logodur.

## Kullanım Kuralları

- **Oranı bozma:** Görselleri `aspect-ratio`'yu koruyarak ölçeklendirin, sündürmeyin.
- **Recolor/Filter:** Kesinlikle CSS filter (`brightness`, `contrast`, `invert`) veya renk değişimi uygulamayın. Pikselleri orijinal bırakın.
- **Zemin uyumu:** Koyu markı açık zeminde, açık markı koyu zeminde kullanmayın. Zemin renklerine uyumlu varyantı tercih edin.
- **Güvenli boşluk (Padding):** Markın çevresinde yeterli boşluk bırakın; logoyu diğer UI elemanlarına veya ekran kenarına yapıştırmayın.
- **Favicon:** Yalnızca mark (ikon) dosyalarını favicon olarak kullanın, tam logoyu kullanmayın. (Bkz: `frontend/public/` dizini altındaki PNG faviconları).

*Not: Bu dosyalardaki kaynak PNG'ler onaylı Concept 1 çalışmasından doğrudan, yapay zekâ filtresi olmaksızın, katı bounding box ile türetilmiştir.*
